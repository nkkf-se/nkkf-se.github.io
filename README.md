# nkkf-se.github.io

Webbplats för **Nynäshamns Kinesiska Kulturförening**, publicerad med GitHub Pages på
https://nkkf.se (även https://nkkf-se.github.io)

Enkel statisk HTML/CSS – inga byggsteg.

- `index.html` – startsida
- `stadgar.html` – föreningens stadgar
- `bli-medlem.html` – formulär för medlemsansökan och kontakt
- `tack.html` – tacksida efter formuläret
- `images/` – bilder
- `CNAME` – egen domän (nkkf.se)
- `style.css` – gemensam stil

Förhandsgranska lokalt: `python3 -m http.server` och öppna http://localhost:8000

Medlemsformuläret skickas via [FormSubmit](https://formsubmit.co) till admin@nkkf.se. Första inskickade formuläret utlöser ett aktiveringsmejl som måste bekräftas.
